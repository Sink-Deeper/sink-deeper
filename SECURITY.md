# Security

If you find a vulnerability in Sinkdeeper, please report it privately to **info@sinkdeeper.com** instead of opening a
public issue, so it can be fixed before it's disclosed.

Helpful to include: what you found, the steps to reproduce it, and what an attacker could do with it. Please don't access
other people's accounts or data beyond what's needed to show the problem, and don't run tests that degrade the live site.

You'll get a reply as soon as possible, and credit if you'd like it once the fix is out.
